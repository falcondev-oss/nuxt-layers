# @falcondev-oss/nuxt-layers-base for LLMs

Everything below is auto-imported in a project that extends this layer. Components are registered without path prefix. UI copy defaults are German.

Prefer these over hand-rolled equivalents or raw `@nuxt/ui` where one fits.

## Composables

| Composable                                 | Use when                                                                                                                                                                     | Signature                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useDialog()`                              | Asking the user something in a modal and awaiting the answer                                                                                                                 | `askConfirm(opts)` → `boolean`; `askSelect({ ...opts, items, defaultValue? })` → picked value or `undefined`; presets `askDelete`, `askArchive`, `askRestore`, `askDiscard` (each takes optional `Partial<AskOptions>` overrides). `AskOptions`: `title`, `description?` (a string, or a `templateParts` text that highlights its values), `body?: () => VNodeChild` (content above the items, e.g. a warning or input), `confirmLabel?`, `cancelLabel?`, `confirmDisabled?: () => boolean`, `color?` |
| `useToast()`                               | Showing a toast. Overrides Nuxt UI's `useToast`                                                                                                                              | Same as Nuxt UI, plus `add({ preset: 'success' \| 'error' \| 'warning', ... })` for color and icon                                                                                                                                                                                                                                                                                                                                                                                                    |
| `usePreventPageLeave(when?, opts?)`        | Guarding against leaving a page (route change and tab close) with unsaved state. `UForm` already does this                                                                   | `when: MaybeRefOrGetter<boolean>` (default `true`), `opts: { leaveTitle?, leaveDescription? }`                                                                                                                                                                                                                                                                                                                                                                                                        |
| `useRouteParamString(name, { optional? })` | Reading a route param as a writable `string` ref. Throws if missing (unless `optional: true`) or not a string. Setting it on an optional param navigates to `<route>-<name>` | Returns `WritableComputedRef<string>` or `<string \| undefined>`                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `useTableColumns(columns, actions?)`       | Building `UTable` columns with an actions column                                                                                                                             | `columns: MaybeRefOrGetter<TableColumn<Row>[]>`; generic param is the data ref type. `actions: { onDelete?(row), headerActions?: ButtonProps[], rowActions?: ButtonProps[] \| (row) => ButtonProps[] }`                                                                                                                                                                                                                                                                                               |
| `useStableColumnWidths(tableRef)`          | Stopping `UTable` columns from jumping width when rows are filtered                                                                                                          | Pass the `UTable` template ref. Returns `{ freeze() }` to re-measure after late data                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `useToolbar()`                             | Adding tools to the enclosing `LayoutNavbar` toolbar from a nested page or component. Throws outside a `LayoutNavbar`                                                        | `addTool(tool \| getter)` (removed on unmount, returns `remove`), `tools`                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `useCardActionsTarget()`                   | Teleporting content (e.g. table header actions) into the header of the enclosing `UPageSection`                                                                              | Returns a selector for `<Teleport to>`, `undefined` outside one                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `useDisabled()`                            | Making a custom input respect an ancestor `UDisabled`                                                                                                                        | Returns `ComputedRef<boolean>`                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `useFreeSpace(target)`                     | Measuring horizontal room a target has in its row, to decide what still fits (overflow menus, wrapping). Low level, used by `UOverflowButtons` and `LayoutNavbar`            | Returns `Ref<number>` (px, `Infinity` until measured). Spread `useFreeSpace.root` on the row, `useFreeSpace.free` on filler that counts as empty, `useFreeSpace.yielding(minShare?)` on content that wraps to give way                                                                                                                                                                                                                                                                                |
| `useTrpc()`                                | Accessing the tRPC client provided by `trpcPlugin`                                                                                                                           | Returns `useNuxtApp().$trpc`                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `createUsable(factory)`                    | Memoizing a factory per argument tuple (like `createGlobalState` with args)                                                                                                  | Returns the factory with the same signature                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## Writing components in this layer

- Define components with `defineSetupComponent((_: { props, emits?, slots?, propKeys?, expose? }) => options(_, { name, props: [...], emits: [...], setup }))`. Types come from the `_` annotation; `props` lists runtime keys.
- Pass slots to third-party components with `v-slots={vSlots(Component, { ... })}` for type checking.
